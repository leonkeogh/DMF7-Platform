# Security Policy

## Reporting a Vulnerability
If you believe you have found a security vulnerability, please report it privately.

- Do not open a public GitHub issue for security problems.
- Include steps to reproduce, impact assessment, and any relevant logs/screenshots.

## Preferred Contact
- Email: security@<your-domain>
- Subject: [DMF7 Security] <short summary>

## Response Targets
- Initial acknowledgement: within 72 hours
- Triage: within 7 days
- Fix timeline: depends on severity and complexity
